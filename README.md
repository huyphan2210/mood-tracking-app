## Why this app is built?

This project was originally intended to help me practice and refine my skills as a software engineer. However, as I worked through it, I found that my interest in taking it seriously has grown. 

This app is designed to help users track their mood and sleep daily. Based on the information provided, it can provide behavioral insights and reflective suggestions to assist individuals in improving their well-being.

For more details about my architectural decisions, the technologies I used, and the reasons behind certain choices, please refer to the `README.md` files in each folder.
